## Atajos de teclado

### En todo Maya

| Atajo | Herramienta | Qué hace |
|---|---|---|
| <kbd>Tab</kbd> <kbd>Tab</kbd> (rápido) | Radial | Abre o cierra el menú radial bajo el ratón |
| <kbd>Tab</kbd> <kbd>Tab</kbd> mantenido + soltar sobre un botón | Radial | Gesto rápido: ejecuta y cierra |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>S</kbd> (Mac: <kbd>⌘</kbd>+<kbd>Alt</kbd>+<kbd>S</kbd>) | SimpleSave | Guardar versión |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Maya | Guarda encima de la versión abierta |
| <kbd>6</kbd> en el visor | Maya | Modo con texturas: para ver las de Árboles y Trepadora |

### En el tablero de Muro

| Atajo | Qué hace |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Pegar una imagen |
| <kbd>F</kbd> / <kbd>A</kbd> | Encuadrar lo seleccionado / verlo todo |
| <kbd>Ctrl</kbd>+<kbd>G</kbd> | Meter lo seleccionado en un marco |
| <kbd>N</kbd> / <kbd>L</kbd> | Nota / lista de tareas |
| <kbd>W</kbd> / <kbd>P</kbd> | Flecha / lápiz |
| <kbd>I</kbd> | Cuentagotas |
| <kbd>G</kbd> / <kbd>H</kbd> / <kbd>C</kbd> | Gris / voltear / recortar |
| <kbd>Espacio</kbd> + arrastrar | Desplazarse |
| <kbd>Esc</kbd> | Dejar la herramienta |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Deshacer dentro del tablero |

### Al trabajar con las herramientas

| Atajo | Herramienta | Qué hace |
|---|---|---|
| <kbd>Esc</kbd> | Trepadora | Detiene el crecimiento y conserva lo crecido |
| <kbd>Q</kbd> | Trepadora | Termina de recortar ramas |
| <kbd>H</kbd> | Trepadora | Oculta las zonas prohibidas (se siguen respetando) |
| <kbd>Esc</kbd> | Árboles | Termina de añadir ramas o de plantar |
| <kbd>Ctrl</kbd> + pincel | GrassEditor | Borra hierba |
| <kbd>Esc</kbd> | LightManager | Termina de apuntar o colocar luces |
| <kbd>Mayús</kbd> + clic | Radial | Abre las opciones de la orden |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Todas | Cada acción se deshace de una vez |

### Atajos que puedes poner tú

En **Windows › Settings/Preferences › Hotkey Editor**, categoría **Custom Scripts**, hay órdenes de Materials
(`MaterialsAbrir`, `MaterialsAsignar`, `MaterialsCuentagotas`, `MaterialsEnviarPainter`) y de LightManager
(«Apuntar», «Tres puntos», «Quitar todos los solos»). Las órdenes de todas las herramientas aparecen también en el
buscador de [Radial](radial.md).
